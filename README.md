# FotiVidio - Video Editing Pipeline

Pipeline de edição de vídeo com chromakey, B-rolls, split screen, zoom effects, e áudio.

## Ferramentas utilizadas

- **Magnific** (20k créditos) - Geração de imagens de fundo, B-rolls animados, música
- **HeyGen** (149 créditos) - Video Agent para edição com IA
- **Highsfield** (38 créditos) - Análise de cenas
- **FFmpeg** - Chromakey, zoom, split screen, composição final
